# Agent Tool & Workflow Mappings

## 1. TickTick Task Harvester
- **Objective:** Extract actionable items from personal list categories.
- **Endpoints Used:** `GET /v2/task` via the TickTick REST API.
- **Output Schema:** Clean array of dictionaries containing `title`, `dueDate`, and `priority`.

## 2. Calendar Event Scheduler
- **Objective:** Interrogate open time blocks and claim calendar real estate for tasks.
- **Data Dependency:** Takes the payload generated by the Task Harvester.
- **Logic Rule:** Check current calendar commitments; place tasks around pre-existing lunch, dinner, or focus slots.

## 3. Contextual Email Drafter
- **Objective:** Process high-priority, unread inbound communications and lay down initial draft blocks.
- **Endpoints Used:** Gmail/Outlook draft sandbox endpoints.
- **Guardrail:** Never send a message autonomously. Only leave drafts in the staging folder for manual review.

## 4. Home Assistant Dispatcher
- **Objective:** Trigger local scenes, track helper states, or fire actions based on workflow execution.
- **Communication Protocol:** Outbound HTTP POST webhooks to the local instance API.
- **Safety Boundary:** Limited purely to non-critical lighting or user presence status toggles.
